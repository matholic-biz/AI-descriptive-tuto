# AI 서술형첨삭 튜토리얼 사이트

매쓰홀릭 **AI 서술형첨삭** 기능의 온보딩 튜토리얼 사이트입니다.
학습지 출제 → OMR 답안지 출력 → AI 자동채점·첨삭까지, 전체 흐름을 화면 캡처 기반 단계별 튜토리얼로 안내합니다.

## 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 홈 화면 — 기능 소개, 튜토리얼 메뉴, 진행률, 경쟁 서비스 대비 차별점 |
| `tutorial-1.html` | Ⅰ. 서술형 학습지 출제 (내신 빈출 문항으로 서술형 학습지 만들기) |
| `tutorial-2.html` | Ⅱ. OMR답안지 출력 (서술형 답안 영역 조정 후 출력) |
| `tutorial-3.html` | Ⅲ. OMR 답안 입력 & AI 채점 확인 (답안 업로드부터 AI 첨삭 확인까지) |
| `support.js` | 튜토리얼 화면(`.dc.html` 형식)을 구동하는 렌더링 런타임 |
| `_ds/` | 매쓰홀릭 디자인 시스템 (SUIT 폰트, 컬러 토큰, 컴포넌트 번들) |
| `uploads/t1`, `t2`, `t3` | 각 튜토리얼에서 사용하는 화면 캡처 이미지 · 영상 |
| `assets/` | 로고 등 공통 이미지 |

## 특징

- **상단 고정 네비게이션** — 모든 페이지에서 홈/Ⅰ/Ⅱ/Ⅲ로 바로 이동
- **섹션 완료 팝업** — 각 튜토리얼 마지막 단계에서 `이 섹션 완료 표시 / 다음 섹션으로 / 처음으로` 선택
- **진행률 저장** — 완료한 섹션은 브라우저 `localStorage`에 저장되어 홈 화면 진행률에 반영
- **포인트 컬러** — `#6155F5` (AI 서술형첨삭 전용 보라색)

## 로컬에서 보기

`index.html`을 브라우저로 열면 됩니다. (튜토리얼 화면은 React를 CDN에서 불러오므로 인터넷 연결이 필요합니다.)

## 배포

빌드가 필요 없는 정적 사이트입니다.

- **Vercel** — 이 저장소를 Import 한 뒤 Framework Preset을 `Other`, Build Command 없음, Output Directory를 루트(`./`)로 두면 그대로 배포됩니다.
- **GitHub Pages** — Settings → Pages에서 브랜치를 `main` / 루트(`/`)로 지정하면 배포됩니다.
